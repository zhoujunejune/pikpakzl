应用与安全

一个登录入口，两个独立服务

数据服务阿里云 HTTPS，同源接口
登录保护沿用 Caddy Basic Auth
自动刷新页面可见时每10秒
交易 API 密钥不存储在本 App
交易策略与止盈止损由原系统独立管理，不作修改
如需修改跟随开关、交易金额、止损或资金账户，请进入5分钟机器人原控制台。关闭本 App 不会关闭服务器机器人；本 App 也不会擅自提交订单。
安装到安卓桌面

用 Chrome 打开当前 /app/ 页面，点右上角「⋮」→「安装应用」或「添加到主屏幕」。以后点 ZL 图标就可进入统一控制台。

登录态由浏览器及服务器负责；不要在公共设备保存密码。
